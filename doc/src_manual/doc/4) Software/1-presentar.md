# Presentación del software

El software está disponible en el servidor global [GitHub](https://github.com/TonyDiana/PyOECF) para su descarga. En él se encuentra el [manual del usuario](https://tonydiana.github.io/PyOECF/), las [instrucciones de instalación][instalacion] y las [descargas](https://github.com/TonyDiana/PyOECF/releases).

Debe descargar la versión correspondiente a su sistema operativo.

Tenga presente que:

- El programa no se instala, funciona como un *portable*: basta con ejecutarlo desde la carpeta donde se encuentre.

- Cuando aparezca una nueva versión, descargue la nueva y elimine la anterior.

- Guarde el programa en algún lugar donde luego pueda encontrarlo con facilidad.

- Hay versión para Windows[^win], macOS[^mac] (solo equipos con Apple Silicon, M1 o posterior) y Linux.

- La primera vez que lo abra, el sistema operativo puede avisar de que el programa no está firmado. Las [instrucciones de instalación][instalacion] explican cómo abrirlo en cada sistema.





[^win]: Es una marca registrada de *Microsoft Corporation*.

[^mac]: Es una marca registrada de *Apple Inc.*

[instalacion]: https://github.com/TonyDiana/PyOECF/blob/deploy/INSTALACION.md
