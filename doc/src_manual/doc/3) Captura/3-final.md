# Finalizar la captura

Las fotografías se descargarán a un soporte de almacenamiento digital y no deberán manipularse ni alterarse con ningún software. En caso de querer verificarlas, realice una copia en otra carpeta del soporte para visualizarlas.

Se recomienda colocar las fotografías en una carpeta exclusiva para ellas, ya que el software creará nuevas carpetas con los resultados y análisis.

Si es posible, analice las tomas inmediatamente después de la captura, sin desmontar la escena, por si fuera necesario repetir el proceso.
