# Primeros resultados del análisis { #resultados }



![img](img/1-00.png){ .centrada }

Tras lanzar el proceso de análisis, se dispondrá de los primeros resultados, en la carpeta `OECF/ANALISIS`, que consisten en:

- Una hoja de cálculo con la primera información obtenida.
- Un PDF con el resumen de la hoja de cálculo.
- Los archivos PSD para verificar el comportamiento en diferentes soportes (siempre al 100 % y, adicionalmente, en el tamaño elegido).
