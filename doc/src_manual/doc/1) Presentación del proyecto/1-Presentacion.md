# ¿Qué es?

{% include "_rec/includes/1-Presentacion.md" %}

Este software, junto con el procedimiento descrito en esta guía, permite:

- Obtener la curva OECF de respuesta del sensor.

- Disponer de un gráfico del rango dinámico de respuesta del sensor de la cámara.

- Caracterizar y calibrar la desviación lumínica del sensor de la cámara o del proceso de revelado.

- Conocer la respuesta de cada una de las zonas lumínicas de captura del sensor, según el sistema de zonas de [Ansel Adams](https://www.anseladams.com).

- Caracterizar la desviación del exposímetro de la cámara o confirmar su exactitud.

- Conocer la temperatura de color real con la que trabaja la cámara al seleccionar uno de sus modos.

- Obtener un archivo que permita la calibración de contrastes en diferentes dispositivos.

- Diseñar un procedimiento para la modificación de contrastes al realizar impresiones o revelados para distintos dispositivos o soportes.
