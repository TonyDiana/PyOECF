# Aspectos a considerar { #aspectos_considerar }

Aunque este producto ha sido diseñado principalmente para su uso en el aula, nada impide utilizarlo en otros contextos, ya sea con fines recreativos, por interés personal o para la autoformación.

Los pasos deben seguirse en un orden estricto, ya que el software debe tomar ciertas decisiones y no incorpora ningún tipo de inteligencia artificial. Por ello, es necesario seguir el procedimiento establecido, pues el programa espera una única opción y no puede tomar decisiones fuera de lo previsto.

Este software reduce significativamente el tiempo requerido para realizar el procedimiento de forma manual y, además, aumenta exponencialmente la fiabilidad y validez de sus conclusiones. Por ello, se recomienda a los usuarios dedicar el tiempo necesario para completar el proceso paso a paso.

Los resultados que pueden obtenerse amplían la tesis de licenciatura en fotografía del [autor de ambos trabajos](https://repositorio.utn.ac.cr/items/ed72f1ae-c478-4b27-a1fb-d0c0b1d7495e).

> *No se ofrece garantía alguna sobre los resultados o conclusiones a los que cada persona pueda llegar, tanto con el texto mencionado como con esta herramienta. Se insta a que cualquier usuario de cualquiera de ellos haga uso de su juicio e intelecto para alcanzar los propósitos deseados*.

Este procedimiento está pensado para cámaras digitales configuradas fotométricamente para medir la luz en tercios de paso. Cualquier otro tipo de cámara, celular, escaneado de negativos, etc... queda fuera de los alcances e intereses de este trabajo.
